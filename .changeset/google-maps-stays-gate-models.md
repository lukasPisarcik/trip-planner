Move the trip map to Google Maps, add an Accommodation tab, a site password gate, and the Claude 5 model family.

- **Google map backdrop.** `TripMap` is rebuilt on the Google Maps JavaScript API (advanced markers, vector Map ID) because the Leaflet backdrop was "basically unusable" on phones — a one-finger drag panned the map instead of scrolling the page. Inline maps now use cooperative gestures (one finger scrolls, two fingers pan; fullscreen keeps free panning), fit-bounds padding accounts for the glass hero and the scrolled-away slice so pins stop spawning under the overlays, the hero condenses and fades while you interact with the map, small screens get a shorter map, and the fullscreen stage now stacks below the AI drawer. Theme flips rebuild the map in the matching light/dark color scheme. Requires `PUBLIC_GOOGLE_MAPS_API_KEY` (+ optional `PUBLIC_GOOGLE_MAPS_MAP_ID`); without a key trips fall back to the solid hero exactly as before.
- **Google Maps hand-off + KML export.** Every marker's info window and every coord-bearing itinerary/restaurant/viral/stay card links "Open in Google Maps", and a new ⬇ map control downloads a whole-trip KML (spots grouped by category) that imports cleanly into Google My Maps — the closest automated path to "all my pins in the Google Maps app", since My Maps has no public API.
- **Accommodation tab.** Trips gain an optional 🛏️ Stay section mirroring the restaurants pattern: the co-pilot researches Hostelworld/Booking/Airbnb via web search and writes it with a new `replace_accommodation` tool — per city 2–4 picks with type, price-per-night snapshot, 0–10 rating, tags, booking link, and coords that plot as violet "stay" pins on the trip map. Empty tabs show a nudge to ask the co-pilot.
- **Site password gate.** Setting `SITE_PASSWORD` arms a shared-password gate over the whole app: pages redirect to a new glass `/login` (30-day signed httpOnly cookie, HMAC-derived so rotating the password signs everyone out), API and remote-function calls get 401s, and the MCP bridge stays reachable only when it enforces its own bearer secret — so the gate can't be bypassed through it. Unset, nothing changes; the public Vercel viewer can now be password-protected without the ~$150/mo platform add-on.
- **Claude 5 models.** The co-pilot picker now offers Claude Fable 5 (Frontier), Opus 5 (Most capable), Sonnet 5 (Balanced) and Haiku 4.5 (Fastest) — replacing Opus 4.8 / Sonnet 4.6 — with Sonnet 5 as the default and new-trip builds auto-upgrading to Opus 5. A previously-selected retired model falls back to the default silently.
